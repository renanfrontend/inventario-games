# Estudo de Caso: Inventário de Games

Este projeto é um estudo de caso desenvolvido para a aula de **Processamento de Dados Massivos e Módulos de Aprendizado**.

## Sobre o estudo

O script apresenta a criação e o gerenciamento de uma tabela de inventário de games. A atividade demonstra conceitos básicos de banco de dados, incluindo:

- criação de tabela com identificador autoincrementável;
- inserção de dados de produtos;
- consulta dos registros cadastrados;
- identificação de itens com estoque crítico;
- filtragem de periféricos com preço acima de um determinado valor.

## Arquivo

- `inventario_games.sql`: script SQL utilizado no estudo de caso.

## Objetivo

Aplicar conceitos de organização, armazenamento e consulta de dados em um cenário prático de controle de estoque.
